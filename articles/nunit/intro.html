    NUnit Documentation

    NUnit is the open-source unit-testing framework for all .NET languages. This section documents the NUnit framework, NUnitLite and the NUnit Console, from NUnit 3 up to the current version, NUnit 5.

    Most of the content applies to all these versions. Where a feature was added or changed in a specific version, the page says so, for example "This constraint was added in NUnit 4.2". Behavior from earlier versions is described in notes or in sections such as NUnit 4 and earlier.

    Where to start

    • New to NUnit? Start with Installation to create a test project, and then Ordinary Tests to write your first test.
    • Moving to NUnit 5? See What's new in NUnit 5 and the breaking changes in NUnit 5.
    • Looking for a specific attribute, assertion or constraint? See Attributes, Assertions and Constraints.
    • What changed in a release? See the release notes.

    The documentation home page gives an overview of everything, including the test adapter, the analyzers and the NUnit engine.

    NUnit 2

    NUnit 2 is a different product, with its own design and its own documentation. It is not covered here. Its documentation is kept in the Archive.
